# Playroom

Party games for kitty parties, couples, drinking nights and house parties.

- Play on one phone, or open a room so every friend sees each card on their own phone.
- `server.js` serves the page and runs the live rooms (WebSocket).
- `index.html` is the whole app.

Run it on your computer:

    npm install
    npm start

Then open http://localhost:3000

Deploy on Render with `render.yaml` (New, Blueprint).
